Career Goals

My career direction, development plan, and the steps I want to take toward becoming a professional web developer.

Short-Term • 1–2 Years

  • Improve HTML, CSS, and JavaScript skills.
  • Build more responsive and interactive websites.
  • Create portfolio projects that demonstrate my abilities.
  • Gain practical experience through internships, freelance work, or entry-level opportunities.

Mid-Term • 3–5 Years

  • Work as a professional web developer.
  • Develop stronger skills in modern web technologies.
  • Contribute to real-world web projects.
  • Continue improving my problem-solving and software development practices.

Long-Term • 7–10 Years

  • Become an experienced and dependable web developer.
  • Handle larger and more complex web projects independently.
  • Keep learning new technologies and industry practices.
  • Potentially take leadership responsibilities in web development projects.

Web Development / Information Technology

Skill Development Plan

  • Practice HTML and CSS by creating responsive websites.
  • Study JavaScript regularly and build interactive projects.

Motivation & Values

My motivation is to turn my interest in technology into a professional career. I value continuous learning, adaptability, problem-solving, effective communication, and creating work that is useful to others. These values encourage me to keep improving and prepare for a career in web development.
