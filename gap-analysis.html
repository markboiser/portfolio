Gap Analysis

This page compares my current skills with the skills required for my future career goal in web development and IT. It also presents my plans for improving the skills that I still need to strengthen.

Career Goal

My career goal is to become a skilled software and web developer who can create functional, user-friendly, secure, and reliable applications.

Based on my current projects and skills, I already have experience with HTML, CSS, JavaScript, Java, PHP, MySQL, GitHub, and GitHub Pages. However, I still need to strengthen several technical and professional skills to become more prepared for a professional IT career.

01

Advanced JavaScript

Current Skill

I have beginner-level experience with JavaScript and have used it for basic website interactivity.

Skill Required

I need stronger knowledge of modern JavaScript, asynchronous programming, APIs, DOM manipulation, and JavaScript frameworks.

Improvement Plan

I will study JavaScript through online courses and practice by creating interactive websites and small web applications. After strengthening my fundamentals, I plan to explore frameworks such as React.

02

Advanced Database Management

Current Skill

I have beginner-level experience with MySQL, SQL queries, tables, and CRUD operations.

Skill Required

A professional developer needs stronger knowledge of database relationships, normalization, advanced SQL queries, and practical database design.

Improvement Plan

I will continue practicing MySQL by creating projects with multiple related tables. I will also study database normalization, relationships, joins, and more advanced SQL queries.

03

Backend Development

Current Skill

I have introductory experience with PHP and have created basic CRUD applications connected to MySQL.

Skill Required

I need to improve my understanding of server-side programming, APIs, authentication, application architecture, and backend frameworks.

Improvement Plan

I will create more PHP/MySQL projects and study backend concepts. I also plan to learn how APIs work and eventually explore technologies such as Node.js and Express.

04

Cybersecurity Fundamentals

Current Skill

I have basic awareness of passwords, account security, privacy, and safe computing practices.

Skill Required

Web developers need to understand secure coding, authentication, authorization, data protection, and common security risks.

Improvement Plan

I will study beginner cybersecurity courses and learn how to apply basic security practices to my applications. I will also learn how to avoid common problems such as insecure authentication and unsafe database queries.

05

Cloud Computing

Current Skill

I have practical experience deploying a static website through GitHub Pages, but my knowledge of larger cloud platforms is still limited.

Skill Required

I need to understand basic cloud services, application deployment, hosting, storage, and cloud-based development.

Improvement Plan

I will study the fundamentals of cloud computing and explore platforms such as AWS, Microsoft Azure, or Google Cloud. I will practice by deploying simple projects online.

06

Professional Communication

Current Skill

I have experience communicating ideas through academic presentations, written activities, and group projects.

Skill Required

Professional developers need to explain technical concepts, document projects, present solutions, and communicate effectively with teammates and clients.

Improvement Plan

I will practice presenting my projects, writing technical documentation, and explaining programming concepts in a clear and organized way.

Improvement Roadmap

SHORT TERM

Build the Foundation

  • Improve JavaScript fundamentals.
  • Practice PHP and MySQL.
  • Build small web applications.
  • Practice HTML and CSS.
MEDIUM TERM

Expand Technical Skills

  • Learn Git and GitHub workflows.
  • Study cybersecurity fundamentals.
  • Learn backend development and APIs.
  • Explore cloud computing.
LONG TERM

Prepare for Professional Work

  • Build larger real-world projects.
  • Deploy applications online.
  • Build a strong project portfolio.
  • Improve professional communication.
  • Prepare for internship and employment.

My Commitment

My current projects have helped me build a foundation in programming, web development, database management, and deployment. However, I understand that becoming a professional developer requires continuous learning.

I plan to address my skill gaps through self-study, online courses, practice projects, academic activities, and continuous improvement. By following this roadmap, I aim to become more confident and capable of developing complete and professional applications.
